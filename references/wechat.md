# 公众号生产规范

## 内容

- 用单栏短文解释一个核心专业判断，不写成课程 PPT、卡片墙或百科长文。
- 读者可见正文不得超过 500 个 Unicode 字符。
- 计数包含副标题、导语、章节标题、正文、引语、图注和文内 CTA；排除主标题、固定品牌页眉页脚、Logo 替代文字、图片替代文字和分享文案。
- 不得把正文移入图片、替代文字或分享文案规避字数。
- 至少包含 1 张与论点直接相关的获授权原始图、专业解释图或技术图。Logo、二维码、底纹和纯装饰不计。
- MBTI 内容必须写明适用边界；不作心理诊断，不凭一次表现判型，不把偏好当能力或命运。

## 版式

- 使用工作坊教案·红：暖白底、炭黑正文、深红章节和批注线。
- 390px 移动端单栏，正文 17px 左右，行高约 1.9；保持短段落。
- 主标题使用深红左边线或短批注标记；章节之间有明确但克制的层级。
- HTML 使用内联样式、相对本地图片或数据 URL，不依赖远程字体、CSS、脚本或图片。
- 图片清晰、不放大；实际粘贴到公众号后台后仍需检查样式清洗、图片重托管、手机和深色模式。

## 自动生产步骤

1. 将 `AIworkspace/30-wechat/current/article.example.json` 复制为 `article.json`。
2. 写入标题、摘要、导语、2–3 个章节、段落、实质内容图、图注、边界和结尾动作。
3. 将共享专业图复制为 `assets/content-image.png`；保持 `assets/logo.png` 与 Skill 原件一致。
4. 运行 `node <SKILL_DIR>/scripts/build-wechat.mjs --unit <内容单元路径>`，一次生成 `output/article.md`、`article.html`、`share-copy.md`、移动端长图和检查报告。
5. 超过 500 字时压缩逻辑和重复表达，不删边界、不藏字，然后重新运行同一命令。

## 候选交付

- 500 字内 `article.md`；
- 单文件/自包含 `article.html`；
- 由最终 HTML 直接渲染的 780px 宽移动端长图；
- 至少 1 张实质内容图；
- `share-copy.md`；
- 检查报告留在 AIworkspace。

未经员工确认，不复制到 `公众号/`。
