# 短视频生产规范

## 1. 口播内容稿

默认 45–90 秒。先解决内容，再处理机器标记。

结构优先：

```text
具体冲突/错误动作
  -> 为什么常见答案无效
  -> 一个更深的专业判断
  -> 生活化例子或对比
  -> 边界
  -> 下一步行动/官方 CTA
```

要求：

- 前 3–5 秒给冲突或反直觉，不做空泛问候；
- 句子短、能说出口，允许少量“你想一下”“其实”“那问题来了”等自然连接词；
- 口癖有节制，同一词不要机械重复；
- 术语先用人话铺垫，再给专业名称；
- 不用材料不能支撑的 `90%`、`一半`、`所有人` 等绝对数字；
- SW 官方机构叙述贯穿口播、字幕和 CTA。

## 2. MiniMax 唯一机器稿

`voiceover-draft.md` 经员工确认后，生成唯一 `tts-input.txt`。不要再创建内容相同的“标注稿”“完整口播稿”或“干净版”。

- 用标点、短句和段落形成主要节奏。
- 只在当前海外 MiniMax 网页入口已验证支持时使用少量 `<#0.3#>` 一类停顿；不要密集标注。
- 英文字母需拆读时在机器稿中加空格：`MBTI` 写成 `M B T I`，`Fi` 写成 `F I`，`Fe` 写成 `F E`。公开字幕和文稿仍使用标准写法。
- 先用 1–2 句短样测试新模型或新声线，再生成全稿。
- 员工在网页端选择有授权的声音、试听并下载；Skill 不保存账号、Cookie 或密钥。

## 3. 音频回传与质检

把原始音频放到 `AIworkspace/40-video/current/audio-inbox/`。保留原文件，不覆盖、不先转码替代。

检查：

- `ffprobe` 可解码、时长、采样率、声道和编码；
- 首尾是否截断；
- 是否有重复句、长静音、爆音、异常女声/男声或背景人物；
- 内容是否与确认稿一致；
- 语速、重音、自然度和专业词读音是否可接受。

不通过时只返回准确时间点和修改建议，等待员工重新生成音频。

## 4. 视听脚本与画面

真实音频是唯一时间轴。先转写/对齐，再生成：

- `audio-report.json`
- `storyboard.md`
- `scenes.json`
- `subtitles.srt`
- `animation-notes.md`
- Remotion 工程

第一阶段视觉基线：

- 1080×1920、30 fps；
- 上方 SW 品牌/栏目区，中间为主要解释动画和场景区，下方为字幕、页码或品牌收束区；
- 使用完整官方 Logo；暖白/浅灰画布、炭黑正文、SW 深红强调，可用少量冷色辅助区分概念；
- 动画服务理解，优先文字层级、关系线、对比、流程、局部缩放和场景化位图；避免每句一个炫技转场；
- 字幕按语义短句分组，不遮挡主体，不把整段文字一次铺满。

### 首帧封面硬规则

封面同时承担“视频第一帧”和“平台独立上传封面”两个角色。二者必须来自同一张 1080×1920 首帧，不允许各做一版后产生点击前后跳变。

- `scenes.json` 第一镜必须 `start=0`、`visual=cover`，并使用 `assets/cover.png` 的 AI 无文字位图或获授权真实素材。首帧不得先出现黑帧、Logo 动画、空白页或普通正文页。
- 优先沿用同内容单元小红书封面的核心钩子、主视觉和「工作坊教案·红」语言，但必须重新编排为 9:16；禁止把 1080×1440 小红书成图直接拉伸、上下补边或整体缩小贴入视频。
- 视觉结构固定为“轻量官方品牌区 + 相关位图主视觉 + 一句核心标题 + 可选一句补充”。主视觉约占中部有效区 45%–60%；不放正文段落、页码、目录、多个并列卖点或内部流程标签。
- 标题总长 4–28 字，按语义拆成 1–3 行，每行不超过 14 字；标题参考 64–84px，补充句参考 26–34px。只强调一个关键词，不用多色描边、发光字或促销贴纸。
- 画布为 1080×1920。把标题和关键人物/物体放在中央 3:4 安全核心区内（基线 `x=60–940`、`y=240–1680`），并为右侧互动按钮和底部字幕/账号信息保留空间。由于平台展示入口和裁切可能调整，发布前仍须在视频号发布页预览实际裁切。
- 封面镜头至少持续 1.8 秒，通常随第一句钩子保持 1.8–3.5 秒；不额外插入与口播无关的静默片头。第一镜持续更长时，应通过主体局部动作或信息递进保持观看感，而不是 8 秒静态海报。
- `scripts/build-video.mjs` 必须输出 `output/video-cover.png`，并验证它是 1080×1920、素材没有低分辨率放大、标题处于安全区、和视频解码后的第一帧 SSIM ≥0.98。

推荐字段见 `assets/templates/video/scenes.example.json`，每次先填写 `cover-brief.md` 再生成第一镜。

### 时间稳定硬规则

- `scenes.json` 的镜头边界决定画面切换；字幕边界只更新字幕层，不得被当作新镜头。
- 常规镜头不得短于 1.8 秒，优先保持 2.5–8 秒；字幕不得短于 1.2 秒。需要更短的强调镜头时必须在分镜中明确标注并人工复核。
- 音频中的无字幕空隙沿用前一镜头，不能因为没有命中镜头区间而跳到最后一镜或其他默认画面。
- 默认稳定直切。需要转场时，只在镜头边界使用一次 6–12 帧过渡；禁止给每条字幕首尾加整帧淡入淡出。
- 缩放、位移等连续动画以整镜头为周期，字幕变化不得让动画从初始值重新开始。
- 禁止非脚本化的整帧黑闪、白闪、透明帧，以及三帧内“切出去又切回来”的往返强切。

生成后运行：

```bash
node <SKILL_DIR>/scripts/video-qc.mjs \
  --input <内容单元>/AIworkspace/40-video/current/output/video-candidate.mp4
```

报告要求 `blackEvents=[]`、`rapidFlashPairs=[]`、`passed=true`。机器检查通过后仍须以正常速度完整观看一次，并在镜头切换点前后逐帧抽查。

## 5. BGM 与音效

- 旁白清晰度优先；BGM 必须可感知，不能小到形同不存在。
- 使用无版权风险、已授权或现场生成并记录来源的音乐与音效。
- 可用轻侧链让人声出现时 BGM 衰减约 4–7 dB；这是起点，不替代人工试听。
- 开头、观点反转、章节切换和结尾可用少量音效；不要每句话加提示音。
- 检查手机外放和耳机两种听感，不只看波形或响度数字。

## 6. 交付

人工确认后，`短视频/` 只保留当前成片、`video-cover.png`、字幕和最终口播稿。原始音频、分镜、工程、分轨、`video-report.json`、`video-temporal-report.json` 和旧版本留在 AIworkspace。首帧封面或闪烁检查未通过时不得把视频称为候选成片。
