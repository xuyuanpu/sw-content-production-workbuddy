# SW 品牌与机构口径

## 1. 机构身份

- 对外主体统一为 `SW` 或 `Skill&Will`。
- 默认使用机构编辑部语气：清楚、克制、专业、可理解、愿意陪伴读者继续观察。
- 内容核心不是泛化的“16 型人格科普”，而是帮助读者看清：当前任务是什么、问题发生在哪一层、MBTI 能提供什么、什么时候不该只用 MBTI。
- 涉及培训、认证、授权资格、合作方或市场地位的宣传性事实，必须以员工提供的当前有效官方证明为准；没有证明时只做一般专业表达。

## 2. 个人归属铁律

以下信息只允许出现在内部来源登记、授权记录和审计材料中，不得进入任何对外候选：

- 王善平
- 善平老师
- 善平笔记
- 王老师，以及能在当前语境指向同一人的拼音、英文名、缩写、署名、头像说明或栏目名

扫描范围包括标题、摘要、正文、图片文字、图注、封面、口播、字幕、音频开场、作者栏、页眉页脚、文件显示名、话题、分享文案和平台元数据。

不要通过拆字、空格、拼音或图片文字绕过。内部规则列出禁用词不构成对外使用许可。

## 3. 叙述方式

推荐：

- `SW 认为……`
- `在 SW 的教学实践中，我们更关注……`
- `从 MBTI 的视角，可以继续观察……`
- 不带归属的专业解释

禁止：

- 把个人第一人称经历改成“我们曾经……”；
- 把编辑设置的场景冒充学员、咨询或客户真实案例；
- 用类型标签替代诊断、能力判断、职业结论或关系结论；
- 许诺学习效果、证书结果、咨询结果或转化效果。

编辑举例必须写明“编辑设置的假设场景”或用不易误解的等价表达。真实案例必须有授权、脱敏和可追溯来源。

## 4. 当前视觉系统：工作坊教案·红

核心 token：

| 用途 | 色值 |
| --- | --- |
| 近白纸张 | `#FCFAF8` |
| 炭黑正文 | `#2B2929` |
| 深红强调 | `#9E2F3F` |
| 浅红批注底 | `#F6E8E8` |
| 次级灰红 | `#756D6D` |
| 分隔线 | `#D8C4C7` |

视觉目标：专业、可靠、教育培训、亲和、可跟随。

红色只用于章节标签、教学批注、短下划线、重点边线和少量导航。禁止大面积促销红、警示红、婚庆粉和黑红奢华风。正文永远比装饰更重要。

字体优先使用系统中文字体：`PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei`，正文常规字重 400，避免通篇粗体。

## 5. Logo

- 唯一标准文件是 Skill 内 `assets/logo.png`。
- 原始尺寸 800×468，SHA256 为 `0fee5573addd255ab7976ea1b625ff34206f2d4b72987368354539c8e7312c57`。
- 完整、等比例、`object-fit: contain` 使用；不裁切、不拆分、不重绘、不滤镜变色、不低分辨率放大。
- Logo 是品牌标识，不计作公众号的实质内容图。

## 6. 内容动作

默认收束优先级：

1. 给读者一个能立刻执行的观察问题；
2. 邀请评论分享真实体验；
3. 只有材料与产品口径足够时，使用“如需了解 SW 的专业 MBTI 课程或培训，请通过官方渠道咨询”一类机构 CTA。

不要让浅层科普直接承担报名成交；也不要写成个人私信或个人课程邀请。
