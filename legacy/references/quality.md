# 质量验收与停止线

> v1.13 新候选优先采用 [全片导演执行契约](director-contract.md)。旧版逐镜字段清单仅用于历史 schema；新候选以精简 direction、编译结果和实际审片为准。

## 通用

- 原始资料未覆盖，来源文件和 SHA256 可查。
- 来源事实、AI 推导、机构观点、外部事实和待确认项分开。
- 案例、Logo、图片、声音、音乐和视频素材授权状态明确。
- 对外候选无个人归属禁用词和语义变体。
- 个人第一人称没有被冒充为机构亲历。
- 草稿、源码、检查、历史版本只在 AIworkspace。
- 平台目录只含人工确认的当前成品。
- 未执行未经授权的登录、计费、发布、排期或外部发送。

## 小红书

- 每页 1080×1440，无溢出、控制台错误、远程资源和低分辨率放大。
- 封面为 AI 位图或获授权真实素材，标题通顺、语义断行。
- 第 2 页起为单栏文章流，不是重复海报/PPT。
- 逐页图、长图和文案一致；长图直接使用原始主图。
- 专业解释图、原始证据或配图真正帮助理解或真实性；平台排版成品截图不计作解释素材。

## 公众号

- 读者可见正文为 1000～1500 个 Unicode 字符，且没有用空话凑字数。
- 至少 1 张实质内容图；Logo 和装饰不计。
- 正文、HTML、长图、内容图和分享文案齐全且一致。
- 390px 逻辑宽度无横向溢出、截字或低分辨率放大。
- HTML 无远程依赖；富文本复制和纯文本回退可用。
- 少于 1000 字或超过 1500 字时，最终验收页禁用公众号复制，提升脚本拒绝写入 `公众号/`。
- 公众号后台粘贴、图片重托管、手机和深色模式未测时明确写“待人工复核”。
- 固定品牌区完整保留随 Skill 交付的原始头图、尾图、品牌介绍和商标说明；允许调整显示宽度、字号、颜色和间距，不得重写或精简锁定原文。固定品牌区排除在 1000～1500 字正文计数之外。
- 900×383 `cover-wide.png` 与 500×500 `cover-square.png` 同时存在、可解码且尺寸精确；二者来自同一张至少 1000×1000 可裁切像素的无文字主题主视觉。
- 封面主标题与文章标题完全一致并按语义拆为 1～3 行；使用工作坊教案·红、SW 官方 Logo 和机构口径，不用正文图、固定品牌图或 Logo 单图冒充封面。
- 封面源素材的授权/AI 生成来源可查；公众号后台头条和分享裁切未人工预览时明确写“待人工复核”。

## 短视频

- 口播直接从素材与 content-plan 生成，按 science-script.md 做一次内容检查，不以多份策划或独立审稿记录作为出稿条件。
- `voiceover-draft.md` 经员工确认；`tts-input.txt` 是唯一机器稿。
- 口播能直接讲清楚，开场有听下去的理由，解释自然推进；不强制冲突、对话、反问或口语词数量。通读检查生硬表达，对照原文核对人物、讲述关系、事实性质、因果与结果，不能擅改为假设或虚构成功。
- 常规 45～90 秒机器稿包含 3～6 个 0.3～0.6 秒语义边界停顿；不得为 0、连续出现或密集到每句一个。
- 去掉停顿和英文字母拆读后，机器稿与员工确认稿内容一致；不允许借“语气调整”悄悄改变观点、数据或 CTA。
- `voiceover-report.json` 存在且 `passed=true`；未通过时不得提示员工生成音频。
- 声线有授权；原始音频保留并记录哈希、编码和时长。
- 无异常人物声音、截断、重复、异常静音，稿音一致。
- 变速、剪切、降噪或转码写入新工作音频并记录原始/派生哈希、时长和处理命令；原始音频未覆盖。
- `alignment-report.json` 存在且为当前音频、当前 `final-voiceover.md`、当前字幕生成；ASR 稿音匹配通过并包含词级时间证据及至少 3 个人工复核锚点。
- 字幕规范化文本与最终口播稿完全一致，无 ASR 同音错字、重叠、越界或短于 1.2 秒的条目；禁止整体缩放旧时间码充当最终对齐。
- `visual-treatment.md` 完整定义核心视觉命题、起点/终点认知、视觉母题、主体接力线、相机策略、运动能量、素材/视觉元素/声音策略、克制原则和 按内容划分的若干幕交接；不是一组美术风格词。
- `visual-explanation-map.md` 完整覆盖当前动态识别的 B-01～B-N；每项写明观众认知变化、视觉任务、证据、解释价值、主要对应镜头和禁止替代。知识拍数、导演镜头数、最终时间轴镜头数分别统计，不得把知识拍覆盖 N/N 写成“N/N 个完整镜头”。
- `shotbook.json` 使用 schema v3；每个被引用镜头只有一个主视觉任务，并写清前后认知、可实现的画面叙事、开场/结束状态、三平面的内容-运动-目的、1～3 组主体、空象限、主体生命周期、相机运动句、双向交接和三段运动。所有语义拍绑定当前音频中的真实锚词与绝对秒，并写明关系和动作后的可见状态。
- `storyboard-report.json` 使用 v4，绑定当前导演方案/地图/SHOTBOOK/场景/最终口播，`passed=true` 且 `executionPassed=true`。所有时间轴镜头含封面/CTA均有显式 cameraPath、subjectHandoff，并与 SHOTBOOK implementation 一致；组级执行不代表任意节点或文字描述已自动实现。
- 分镜、字幕、动画和成片以当前工作音频为唯一时间轴；音频改变后镜头时长也重新安排。
- 1080×1920、30 fps，视频 H.264 或兼容编码，音频 AAC 或兼容编码；实际用 `ffprobe` 探测。
- 第一镜从 0 秒开始且为封面；`video-cover.png` 为 1080×1920，与解码后第一帧 SSIM ≥0.98。标题和关键主体处于中央 3:4 安全核心区，素材无低分辨率放大。
- 封面沿用小红书的主题钩子、主视觉和工作坊教案红 VI，但已针对 9:16 重排，不是拉伸或补边后的 3:4 成图，也不是正文页、Logo 片头或信息堆叠海报。
- 常规镜头至少 1.8 秒、字幕至少 1.2 秒；画面只在镜头边界切换，字幕边界不做整帧淡入淡出或动画重置。
- `video-report.json` 证明使用 Remotion 逐帧渲染，静态截图循环为 false，`knowledgeLogicRenderer=native-remotion`；`platformLayoutScreenshots=[]` 且视觉导演至少识别 1 个原生知识解释镜头。图片复用不是必选项。
- 短视频不使用纸纹、卷边、胶带或纸片拼贴；按内容设计人物互动、关系变化、对照和证据画面。旧纸片分镜必须重新设计。
- `video-qc.mjs` 检查为 `blackEvents=[]`、`rapidFlashPairs=[]`、`passed=true`；`freezeEvents` 中的静止段交导演解释；主画面超过 2.6 秒的静止段需判断是否承担阅读或理解任务，不强制添加装饰运动。正常速度完整观看和镜头边界抽帧均无闪烁。
- `assets/bgm/sw-brand-bgm.mp3` 实际使用且 SHA256 为 `0be398827ba3f1b4a297748b9b49f6b104d0db5549f08471daf7cc98892b9c7c`；不得换歌、叠加第二首 BGM 或输出无 BGM 候选。
- `mix-report.json.status=passed`，`video-report.json.assets.brandBgm.assetId=sw-brand-bgm-v1`，且两份报告中的母带指纹、截取窗口和最终混音记录一致。
- 固定 BGM 可感知但不压人声，音效不抢信息；手机外放与耳机完整试听通过。

## 最终验收页

- 小红书就绪必须同时满足：3–10 张逐页 PNG、全部 1080×1440、浏览器实际解码显示、缩略图数量一致、正文非空。
- 小红书未就绪时必须显示缺失原因，隐藏空白图片区并禁用上一页、下一页和复制正文；构建报告为失败，不得保留可点击的假按钮。
- 公众号就绪必须同时满足：正文/HTML 可见、字数和内容图合格、900×383 与 500×500 封面可解码并实际显示、封面哈希与当前检查报告一致。任一不满足时显示原因、隐藏无效预览并禁用纯文本和富文本复制。
- 短视频区在音频返回前显示唯一 `tts-input.txt` 及复制按钮；缺少绑定人工确认且当前通过的 `voiceover-report.json` 时必须显示原因并禁用复制。
- 只有小红书、公众号和口播机器稿都就绪、切换与复制均实测通过时，最终验收页才可标记 `passed=true`。短视频成片未生成可以显示等待音频，不得冒充已完成。
- 任一平台更新或缺失后必须重建验收页；旧 HTML 和旧复制载荷不能作为当前验收证据。

## 验收状态

视频构建、总校验、验收页和提升共用 video-acceptance-lib.mjs；以当前 MP4、PNG、SRT 与最终稿四个文件指纹判定，不以历史 passed 自证。候选同时复核当前上游输入；已确认成品使用提升时留在 AIworkspace 的独立报告快照，新候选不影响旧成品的验收。全部平台提升预检通过后才归档旧版；平台目录只保留交付载荷。

严格区分：

1. 静态/机械检查通过；
2. 本地渲染或媒体解码通过；
3. 员工内容确认；
4. MBTI/课程/机构口径专业审核；
5. 人物与素材授权；
6. 品牌确认；
7. 发布授权；
8. 实际已发布。

较弱证据不能替代较强证据。没有实际平台链接或内容 ID，不得写“已发布”。

## 强制停止

- 来源、公开范围、专业依据或授权不清；
- 身份禁用词命中或语义上仍能识别个人归属；
- 个人经历被虚构成机构经历；
- 公众号字数、内容图或 900×383 / 500×500 双封面失败；小红书封面/文章流失败；
- 口播核心判断无依据或原意被改动：标出具体疑点并修正/待确认，不以旧 science-script-report 或论证表单阻止候选交付。
- 视频无确认音频或音频质检失败；
- 固定 SW 原创品牌 BGM 缺失、指纹不符、被替换、未实际混入或混音报告缺失；
- 返回音频与拟采用口播稿明显不一致且员工未作取舍；
- 音频已派生处理但仍沿用旧字幕或镜头，或对齐报告缺失、过期、没有词级事实证据；
- 片级导演方案缺失或只是风格词，视觉解释地图缺失，SHOTBOOK 不是 schema v3 或缺少画面叙事/三平面运动/主体生命周期/相机句/双向交接/动作后状态，机制/案例/边界只用大字糊弄，或分镜报告缺失、过期、未通过；
- 口播机器稿没有语气转换、停顿为 0/过密、确认稿与机器稿内容不一致，或缺少通过的 `voiceover-report.json`；
- 验收页出现平台内容不可见但复制按钮仍可用，或报告未验证组件状态；
- 视频出现整帧黑闪、三帧内往返强切或字幕边界整帧转场；
- 视频仍是字幕切片对应的静态截图循环，使用公众号/小红书排版成品截图，主画面僵住超过 2.6 秒，或知识逻辑没有由 Remotion 原生场景解释；
- 视频第一帧不是正式封面、封面与第一帧不一致、关键内容被裁切或使用低分辨率素材；
- 候选与准备发布版本不一致；
- 需要新增权限、付费、外发或发布而无明确授权。

## 跨平台强制维度：原主题保留

按 SKILL.md 的“原主题保留”逐平台进行语义评估，引用原内容核心问题与当前稿件的专业解释。原内容以 MBTI 为核心，而选题或成稿绕过 MBTI、仅挂名或变成通用建议，判为不通过并退回补充素材或修订；其他形式检查和单项审阅通过不能覆盖此失败。该维度是必做的内容判断，现有程序的关键词命中或结构报告不能代替它。

## 口播建议与读者阻力

行动受阻类题目按 science-script.md 的行动建议说明审查：具体阻力、专业解释与有条件行动是否相连；若只有定义加步骤、虚构转变或效果，退回修改。内容检查引用现稿判断，不凭结构齐全判通过。纯知识、操作演示不强制情绪铺垫。

## 来源改写核对（三平台）

对照原文检查人物与讲述关系、事实或假设性质、因果和结果是否保留。原文案例不能因未核实自动改成假设，编辑添加的步骤不得写成当事人做过的事。转述归属须准确且符合品牌要求，专业确认和公开授权另判。结论与对应来源、稿句写入已有平台审阅记录；口播另按 science-script.md 做真实讲述通读。程序结构通过不能代替这一判断。
